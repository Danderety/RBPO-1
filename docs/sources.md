# Источники для углубления

Карточки описывают именно исходники Faultline. Для общей методики и деталей защит используйте первичные рекомендации OWASP:

- [Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) — организация проверок веб-приложений.
- [SQL Injection Prevention](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html) — параметризованные запросы и границы динамического SQL.
- [Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) — аутентификация, MFA, защита от автоматических попыток.
- [SSRF Prevention](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html) — allowlist, URL/IP-проверки и сетевые ограничения.
- [Chrome DevTools Network](https://developer.chrome.com/docs/devtools/network/reference) — просмотр запросов, статусов и инициаторов.
- [Burp: intercepting HTTP traffic](https://portswigger.net/burp/documentation/desktop/getting-started/intercepting-http-traffic) — встроенный браузер, Intercept и HTTP history.
- [curl man page](https://curl.se/docs/manpage.html) — актуальные параметры командной строки.

Три Cheat Sheet и руководства инструментов доступны при подготовке проекта; страница WSTG не загрузилась через инструмент проверки, ссылка оставлена как справочная. Стенд не является официальной реализацией OWASP и не заявляет полного покрытия WSTG или ASVS.
