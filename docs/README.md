## Порядок работы

1. Запустите свою копию стенда и выполните обычную покупку.
2. Откройте свой отчёт по ссылке выше и подготовьте инструменты по инструкции команд.
3. Сравните обычный и изменённый запрос. Запишите фактический ответ, минимальное доказательство и предложенное исправление.
4. Исправления кода проверяйте в отдельной локальной копии: одновременно проверяйте запрет атаки и работоспособность обычного сценария.
5. Отправляйте в общий репозиторий только `.md` из своей папки.

## Границы выводов

Отсутствие заголовка не доказывает эксплуатацию. Стек ошибки не означает RCE; SQL-инъекция в SQLite не означает выполнение команд ОС. HTTP на loopback не доказывает удалённый перехват. Разграничивайте ожидаемые результаты, собственные наблюдения и возможные последствия в реальном сервисе. У некоторых сценариев общий корень; не считайте одну отсутствующую проверку несколькими независимыми проблемами.
