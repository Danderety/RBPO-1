

# Faultline Shop — учебный магазин

Полноценный локальный стенд для командного изучения веб-безопасности: каталог, поиск, корзина, регистрация, вход, оформление и история заказов, отзывы, админка с покупателями, редактированием товаров и статусами заказов. Данные сохраняются в SQLite. Оплата вымышленная; интеграций с банками нет.

**В приложении намеренно оставлены уязвимости. Это не защищённый шаблон для настоящего магазина.** Наличие собственного стенда не означает прохождение аудита безопасности.

## Быстрый запуск

Требуется Node.js **24+** со встроенным `node:sqlite`. Внешние npm-пакеты не нужны.

```sh
npm start
```

Откройте **http://127.0.0.1:3000** — именно этот адрес, не `localhost`.

| Аккаунт | Пароль | Назначение                                      |
| -------------- | ------------ | --------------------------------------------------------- |
| alice@lab.test | alice123     | Покупатель, заказ № 1                     |
| bob@lab.test   | bob123       | Другой покупатель, заказ № 2        |
| admin@lab.test | admin123     | Админка появляется после входа |

В админке можно смотреть все заказы, фильтровать их по статусам, менять статус, название и цену товара, просматривать покупателей. В корзину можно добавлять товар несколько раз и удалять отдельные позиции. Состав заказа сохраняется в поле `orders.items`; основные сведения видны в кабинете и админке.

## Проверки

```sh
npm test
```

Тест сам создаёт временную БД, запускает отдельный сервер на 3100/3101, проверяет 64 утверждения и удаляет только собственную временную папку. Рабочая БД не меняется. Тесты подтверждают наличие уязвимостей и ограничений стенда, **а не безопасность магазина**. XSS проверяется на уровне сохранения и выдачи опасного HTML; выполнение JavaScript проверяется вручную по инструкции.

```sh
npm run verify
```

Эта команда проверяет уже запущенный стенд на 3000 и **меняет его данные**: создаёт заказы, пользователя, отзыв с XSS-маркером, HTML-файл, меняет адрес и статусы. Запускайте её в своей копии лаборатории.

Для сброса остановите сервер (`Ctrl+C`), выполните `npm run reset`, затем `npm start`. Старая папка данных сохраняется как `data-backup-<timestamp>`. Если вручную меняли порт, сначала остановите и этот экземпляр: reset проверяет только стандартный 3000.

## Границы лаборатории

Серверы слушают только `127.0.0.1`; приложение проверяет Host и блокирует посторонний Origin. SSRF допускает только учебный сервис на 3001 и не следует перенаправлениям. Обход пути ограничен папкой `data`. CSRF демонстрируется внутри origin лаборатории; полноценная атака с чужого сайта здесь заблокирована внешним ограничителем. Не меняйте эти границы при выполнении заданий. Для шести участников — отдельная локальная копия каждому.

Ни контейнерной изоляции, ни защищённого режима в этой версии нет. Командного исполнения, десериализации произвольных объектов, реального перехвата трафика и эксплуатации ОС здесь также нет: темы для будущих отдельных контейнерных упражнений описаны в разделе перспектив архитектуры.
